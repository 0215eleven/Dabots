# Documentation images

| Image | Source and scope | Privacy treatment |
| --- | --- | --- |
| `iphone-conversations.png`, `iphone-chat.png`, `iphone-group.png` | Actual iPhone captures of the native example interface in isolated staging. Used by both project READMEs. | Synthetic conversations and Bot names; no live host, pairing data or private messages. |
| `conversations.png`, `chat.png`, `group.png` | Actual React Native components rendered in this repository's development-only Web preview at 390×844, using example data. Used in the design notes. | Fictional Bot names and conversation content; no real messages, pairing credentials, QR codes or device identifiers. |

The older `conversations.png`, `chat.png` and `group.png` are Web renders; the `iphone-*` images are physical-phone example captures. These images show the stated interfaces and do not establish the full device acceptance matrix. Private reference images and unredacted source captures are not redistributed.
