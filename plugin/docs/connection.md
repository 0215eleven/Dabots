# 手机连接

安装单个 Dabots 插件后，在电脑账户菜单打开“Dabots 手机访问 → App”。只有两个入口：

- **官方登录**（默认）：点击后自动初始化电脑连接；就绪时自动显示二维码，手机扫码即可连接。无需填写中转地址、共享密钥或账号注册表单。名称“官方登录”表示接入官方服务，不建立账号。
- **隧道连接**：下设**临时隧道**与**自有域名隧道**。临时隧道需要本机已安装 cloudflared，每次由主人明确启动；自有域名可以由插件托管 Cloudflare 隧道，也可以填写已运行的 HTTPS 入口（兼容旧 existing/fixed 配置）。

安装本身不会建立公网连接。主人首次选择入口后，Bridge 使用公共 `@deepseek-ai/dsh-home-paths` 的 DSH home 解析，在其 `data/ds-bot-mobile-bridge` 专用子目录初始化状态，并仅监听 loopback。无需手填目录；已有绝对 `home` 覆盖继续使用，不迁移或删除旧设备、密钥、配置。已保存的官方或隧道选择会在重启时恢复；临时隧道仍需手动启动。旧私有中转配置不再展示，选择官方服务使用独立设备签名，绝不继承或发送旧共享密钥。原私有配置文件保留，公开入口选择另存于 `relay-selection.json`。

官方服务内置地址为 `wss://dsbot.ziyuegege.com`，插件不包含全局登记密钥。服务端需要先部署[受限公开登记](../tools/relay/DEPLOYMENT.md)，才能完成正式扫码；插件更新不会自动修改生产配置。离线、额度用尽和拒绝登记时不生成二维码，可以从页面重试。

二维码只在电脑入口就绪后生成，有效期两分钟，当前二维码只允许一台手机消费。主人打开并生成二维码即授权本次扫码；刷新、隐藏、关闭页面、切换入口或连接状态变化会撤销尚未完成的本次授权。拍照后抢先扫码者可能获得这次连接，因此只向自己的手机展示二维码。旧手机继续使用原二维码字段、E2EE 及 access/refresh token 格式。自动配对不授予 Agent 权限；Agent 使用仍由主人单独明确授权。已有待批准请求不会被本次二维码自动批准。浏览器被强制结束或网络中断时，关闭通知可能无法送达，此时原码最多保留到两分钟有效期结束。

已配对设备保留其会话。关闭已完成的二维码不撤销手机；撤销设备请用设备列表中的“撤销”。地址变化后，手机仍绑定原地址，必要时重新配对；切换入口不会删除旧设备。

自有域名的插件托管模式需要固定的非零 loopback 端口，以便 Cloudflare Service URL 在重启后仍有效。可通过现有 Bridge 行覆盖设置端口；端口冲突时会报告失败，不会假装已连通：

```yaml
- id: ds-bot-mobile-bridge
  config:
    port: 7443
```

端口仅为示例。已有固定 HTTPS 或外部 connector 继续可用，不会修改宿主或代理配置。官方入口会停止本插件托管的活动隧道；原域名和 Token 保留。页面关闭只撤销二维码，不等于停止隧道；使用“停止”结束本插件启动的进程。清理失败时按页面提示确认进程已退出，再处理专用 Bridge 目录中的恢复标记。

插件托管的 Cloudflare Token 以**未加密明文**保存在专用目录的 `remote-connection.json`。POSIX 下新文件采用 `0600`；Windows 保护取决于目录 ACL。接口不返回已保存 Token，只报告 `tokenSet`。不要共享或提交二维码、Token、实际配置或测试状态。
