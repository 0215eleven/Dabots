# 兼容与验证边界

## 保留的身份

桌面包名 `ds-bot`、客户端模块 ID、`bot` / `web-search-auto` / `ds-bot-mobile-bridge` 行 ID、协议和存储键保留。iOS 使用 `app.dsbot.mobile` 和 `dsbot` scheme。用户保存的电脑、Bot 和群组名称不被改写。

Bridge 按宿主实际 capabilities 开放功能，不用版本字符串代替能力协商。原版公共引擎缺少可靠提交/脱敏接口时，相关能力保持关闭；正式单包使用仓库内适配后的 0.2.0 源码。

## Agent 权限

DSH Agent 与普通 Bot 是不同的权限表面。电脑所有者按设备明确授权，默认拒绝；撤销后不再提供 Agent 列表、消息及流。手机只提交纯文本，不提供全局工具审批、会话收养或任意工作目录输入。

脱敏只覆盖 Dabots 自己的已知秘密值。模型提供商或 connector 的全局凭据如果被 Agent 回显，不能保证被同一脱敏器消除。现有授予界面会说明这一限制；不能把删掉工具卡片或 `redactedText` 标记当成全局脱敏保证。

## 证据分层

- 单元测试：真实组件边界、状态和错误路径。
- 隔离 DSH：固定公共 DSH 0.2.1-rc.2、仓库生产引擎和 mock 模型，验证配对、消息、权限及重连。
- 单包/迁移：真实归档安装、同一设备令牌和回执、回退。
- iOS JS / prebuild：验证源码打包与原生工程生成，不代表 Xcode 编译。
- 原生构建 / 后签名 / 真机：分别需要实际 macOS 任务、用户签名和设备结果。

测试不连接真实用户 profile。没有真实设备或 macOS 任务结果时，不将模拟检查表述为真机验收。
