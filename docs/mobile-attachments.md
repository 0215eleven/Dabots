# 手机聊天附件

手机和电脑插件都更新后，聊天输入框旁的加号可选择文件或照片。发送前可以预览、替换和移除附件，也可以只发附件。取消上传或上传失败会保留本次选择与文字，允许重试。旧电脑插件没有声明附件能力时，手机保持文字聊天。

- 单个附件 1 字节至 2 MiB；每条消息最多 4 个，合计不超过 4 MiB。
- 图片：PNG、JPEG、WebP。图片还需通过 DSH 图片校验，当前模型须支持图片输入。
- 文件：txt、md、markdown、csv、json、jsonl、log、yaml、yml、xml、pdf、doc、docx、xls、xlsx、ppt、pptx。文件交给 DSH 原生附件服务；具体内容读取仍取决于 Agent 的工具和权限，不承诺 Office/PDF 自动解析。
- 暂不支持视频、音频、压缩包、可执行文件、HEIC 或 AVIF。聊天记录显示附件名称；此版本没有新增历史附件下载入口。

附件只发往当前已配对电脑。官方连接沿用现有端到端加密 RPC，直连沿用原连接。上传收据绑定手机、对话及具体会话，发送仍需原有会话权限；DSH Agent 仍需电脑端授予该手机 Agent 权限。附件不会自动授权执行其中的程序或指令。

电脑在 Bridge 专用目录暂存文件，使用随机文件名而非手机提供的路径。未发送的暂存附件 24 小时过期；每部手机最多暂存 16 个，整台 Bridge 最多 64 个。已确认接收的暂存附件立即删除，文件本身进入 DSH 原生持久附件存储。已收到收据的取消/失败批次会主动删除暂存；响应丢失留下的文件由过期清理回收。手机只清理 App 自己创建的选择器缓存副本，不删除用户原文件。

验证区分：真实隔离 DSH 的 Bot、群聊、Agent 文件/图片持久接收及稳定请求重试；加密中转二进制分块；插件安装/重启/撤销/卸载。网页预览不能代替 iPhone 的相册、文件选择器、权限提示或真实输入法验收。
